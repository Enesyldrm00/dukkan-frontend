# Dükkan Yönetim Sistemi - Frontend

React tabanlı stok ve satış yönetim sistemi arayüzü.

## Teknolojiler
- React
- Vite
- axios
- react-router-dom

## Kurulum
1. `npm install`
2. `npm run dev`
3. Tarayıcıda `localhost:5173` açın

## Sayfalar
- Dashboard - Özet bilgiler, kritik stok ve en çok satan ürünler
- Ürünler - Ürün listeleme, ekleme, düzenleme, silme
- Kategoriler - Kategori listeleme, ekleme, silme
- Satış - Sepet sistemi ile satış yapma ve satış geçmişi
